# Glossario

Usa queste parole sempre con questo significato.

| Parola | Significato |
|---|---|
| Archivio | Il repository privato con i dati di una famiglia (`data/`) e la sua configurazione |
| Engine | Il codice comune: validatore, filtro privacy, generatore del sito |
| Atto | Un singolo documento di stato civile o parrocchiale (nascita, matrimonio, morte) |
| Estratto | Copia breve di un atto rilasciata dal Comune |
| Registro | Il volume che contiene molti atti |
| Indice decennale | Elenco alfabetico degli atti di dieci anni |
| Foglio matricolare | Scheda militare di un uomo, con genitori e nascita |
| Spoglio | Lettura completa di un registro, con l'elenco delle persone trovate |
| Fonte | Un registro, un archivio o un documento da cui viene un dato (`SRCnnn`) |
| Citazione | Il punto preciso di una fonte che prova un fatto (`CITnnn`) |
| Media | Il file di una scansione, foto o PDF (`MEDnnn`) |
| Radice | La persona da cui parte l'albero principale (`tree.root_id`) |
| Linea diretta | Gli antenati diretti della radice |
| Collaterale | Un parente che non è un antenato diretto (fratello, zio, cugino) |
| Ramo scollegato | Una famiglia non ancora collegata alla linea diretta |
| Serie | Un gruppo di schede che parte da una coppia di bisnonni della radice o del coniuge |
| Scheda "?" | La scheda dell'albero per i genitori non ancora trovati |
| TBC | Da confermare: il legame non è ancora provato da un atto |
| Ricerca | Un controllo in un archivio, annotato nel registro ricerche |
| Esito | Il risultato di una ricerca (`found`, `not_found`, ...) |
| Ricerca pianificata | Una ricerca decisa ma non ancora fatta (esito `planned`) |
| Paradato | Un dato sul processo: chi ha cercato o trascritto, come, con quali grafie e strumenti |
| Lettura mirata | Lettura di una sola parte delle pagine, per esempio le strisce con i nomi |
| Conoscenza diretta | Fonte di una persona nota alla famiglia senza un atto (tag `conoscenza_diretta`) |
| Pseudonimo | Il codice `L-…` che sostituisce l'ID di una persona viva nel sito pubblico |
| Fuga | Un nome o un ID di una persona viva rimasto nel sito pubblico |
